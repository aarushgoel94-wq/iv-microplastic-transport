========================================================================
(D) focus_efficiency = 0.88 — what it does
========================================================================

When focus_enabled=True, each step computes focusing blend
  α = 1 − exp(−λ_focus · Δt)
then applies
  α_eff = focus_efficiency · α = 0.88 · α
before moving y toward the centerline: y ← y + α_eff (y_c − y).

It is NOT a physical force. It is a heuristic imperfect-tracking factor.
With focus_enabled=False (paper MAIN), focus_efficiency is inert / unused.
For the main paper tables above, it can be ignored. Keep it only for the
focusing-ON appendix ablation, or delete it if you drop that appendix.
